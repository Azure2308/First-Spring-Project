4) Параметры *KafkaListener*:   
   `id` - id слушателя.   
   `containerFactory` - бин для создания контейнера слушателя.    
   `topics` - топики для прослушивания.    
   `topicPattern` - отбор топиков для прослушивания по регулярному выражению.     
   `topicPartitions` - партиции для прослушивания.     
   `containerGroup` - бин, к которому добавляется контейнер слушателя.     
   `errorHandler` - обработчик.    
   `groupId` - группа потребителей.     
   `idIsGroup` - для groupId берется id слушателя.      
   `clientIdPrefix` - префикс к id.     
   `beanRef` -  бин, к котором определен слушатель.      
   `concurrency` - число одновременных потоков.    
   `autoStartup` - автостарт слушателя при запуске.    
   `properties` - задание/переопределение свойств в аннотации.     
   `splitIterables` - метод вызывается для каждого элемента коллекции.     
   `contentTypeConverter` - указывает бин для десериализации.     
   `batch` - обработка пачек сообщений.     
   `filter` - обработка сообщений по фильтру.     
   `info` - доп инфа в заголовке.     
   `containerPostProcessor` - указвается бин, который используется для настройки контейнера после создания.
