# Что я сделал в задании:
1) Реализовал приложение с разделением прав доступа с использованием аннотации javax.annotation.security.RolesAllowed
2) АПИ:
- public/api - доступ разрешен для всех
- admin/api - доступ разрешен для пользователей с ролью admin
- support/api - доступ разрешен для пользователей  с ролью support
3) Все приватные АПИ возвращают имя и роль пользователя
4) Хранение пользователей в памяти приложения (используется InMemoryUserDetailsManager)
5) Для хеширования паролей используется BCryptPasswordEncoder
6) Используется Basic аутентификация
