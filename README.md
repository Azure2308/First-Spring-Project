## Задание 2: Аннотация @SpringBootApplication
@SpringBootApplication - это аннотация, которая упрощает настройку и запуск приложения. Она отмечает главный класс Spring Boot проекта и включает в себя такие анотации, как: @Configuration, @EnableAutoConfiguration, @ComponentScan.

## Параметры @SpringBootApplication
`nameGenerator` - генератор названий для бинов.  
`exclude` - указывает на классы конфигурации, которые исключаются.  
`excludeName` - указывает на названия классов конфигурации, которые исключаются.  
`proxyBeanMethods` - указывает, должны ли методы @Bean проксироваться для соблюдения поведения жизненного цикла компонента.  
`scanBasePackages` - задает пакеты для сканирования.  
`scanBasePackageClasses` - альтернатива scanBasePackages() для указания пакетов, которые необходимо сканировать на наличие аннотированных компонентов.
